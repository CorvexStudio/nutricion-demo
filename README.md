# Corvex Nutrición · demo

Web compilada de la demostración de Corvex Nutrición (Corvex Studio). Todos los datos son inventados y la base de datos
funciona dentro del navegador de cada visitante: no hay servidor ni datos reales.

- Aplicación: https://corvexstudio.github.io/nutricion-demo/
- Asistentes (llamada y chat): https://corvexstudio.github.io/nutricion-demo/asistentes.html

El código está en un repositorio privado. No editar aquí: se regenera con `scripts/demo_web.py`.
